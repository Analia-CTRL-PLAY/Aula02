Sua Identidade
A primeira coisa que você deve fazer ao instalar o Git é definir o seu nome de usuário e endereço de e-mail. Isso é importante porque todo commit do Git usa essas informações e elas estão incorporadas de forma imutável nos commits que você começa a criar:

$ git config --global user.name "John Doe"
$ git config --global user.email johndoe@example.com

Novamente, você precisa fazer isso apenas uma vez se passar a opção --global, porque então o Git sempre usará essas informações para o seu usuário nesse sistema. Se você quiser substituir isso com um nome ou endereço de e-mail diferente para projetos específicos, poderá executar o comando sem a opção --global quando estiver nesse projeto.
Muitas das ferramentas de GUI ajudarão você a fazer isso quando as executar pela primeira vez.
Seu Editor Agora que sua identidade está configurada, você pode configurar o editor de texto padrão que será usado quando o Git precisar que você digite uma mensagem. Se não estiver configurado, o Git usará o editor padrão do seu sistema. Se você quiser usar um editor de texto diferente, como o Emacs, pode fazer o seguinte: $ git config --global core.editor emacs Em um sistema Windows, se você quiser usar um editor de texto diferente, deverá especificar o caminho completo para seu arquivo executável.
